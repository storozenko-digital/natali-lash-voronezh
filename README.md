# Natali Lash

Одностраничный сайт мастера по наращиванию ресниц в Воронеже.

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий GitHub с основной веткой `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь завершения процесса **Publish website to GitHub Pages**.
5. Готовая ссылка появится в **Settings → Pages**.

Сайт публикуется из папки `dist` автоматически после каждого обновления ветки `main`.
